CLI and Frontend Wallet Management Guide

Developer CLI Wallet Connection

Manage your developer identity and verify balances using the `dfx` CLI directly:

# 1. View current active CLI identity
dfx identity whoami

# 2. Get active identity's principal
dfx identity get-principal

# 3. Use a custom named identity
dfx identity use <identity-name>

# 4. Check ledger balance on mainnet (ic) or local
dfx ledger --network ic balance
dfx ledger balance

💡 Use the pre-configured script ./scripts/wallet_manager.sh in this repository for automated developer CLI management!

How to Integrate Multi-Wallet Support in Your Frontend

Our code includes standard adapters to request and initialize authorized canister actors. Below is the pattern to instantiate a backend actor using the authenticated identity:

import { HttpAgent, Actor } from "@dfinity/agent";
import { AuthClient } from "@dfinity/auth-client";

// After authenticating with AuthClient:
const identity = authClient.getIdentity();
const agent = new HttpAgent({ identity });

// Construct the canister actor
const ammActor = Actor.createActor(idlFactory, {
  agent,
  canisterId,
});
